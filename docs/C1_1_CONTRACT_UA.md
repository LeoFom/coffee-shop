# C1.1 — контракт між Coffeo web та API

Версійний BFF доступний як `/api/v1/...` і передає запити до Fastify `/v1/...`. Він допускає тільки визначені маршрути, перевіряє query та JSON через схеми `lib/contracts/v1/schema.ts`, а успішну відповідь API перевіряє ще раз перед поверненням браузеру. Невідома операція повертає 404; невідоме поле запису — 400; некоректна відповідь API — 502. Помилки мають форму `ApiError`. Cookie оновленої сесії передаються далі, а відповідь має `no-store`.

Копія схеми API прив'язана до SHA-256 та commit API у `lib/contracts/v1/contract-lock.json`. `npm run contract:check` виявляє зміну копії без оновлення контрольної суми. `npm run test:contracts` перевіряє DTO, маршрути, суворість запису, помилки та cookie. OpenAPI й перелік підтриманих/зарезервованих операцій зберігаються в API repo: `docs/C1_1_CONTRACT_UA.md`, `openapi/coffeo.v1.json`.

Наявні сторінки магазину поки користуються legacy BFF, тому їхня поведінка не змінюється під час C1.1. Переведення auth, кошика та checkout на v1 відбуватиметься після реалізації відповідних інваріантів. Зарезервовані `/api/v1/cart/items`, `/api/v1/orders` і `/api/v1/admin/products` не виконують продажів чи змін товарів.
